# Live MCP verification

When asked to run live interoperability checks, follow [TESTS.md](TESTS.md).
Use the connected server's actual tool names and record PASS, FAIL, or SKIP
with a reason for each check. Live Ask calls use provider quota.

This checklist does not replace `npm test` or the repository harness. Ordinary
source changes use the automated suite described in [AGENTS.md](../AGENTS.md).
